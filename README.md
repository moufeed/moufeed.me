# M−MOFID Portfolio

Personal portfolio site built with [Astro](https://astro.build/), React islands, and Sass.

## Setup

```bash
npm install
npm run dev
```

## Scripts

| Command           | Description              |
| ----------------- | ------------------------ |
| `npm run dev`     | Start local dev server   |
| `npm run build`   | Build static site to `dist/` |
| `npm run preview` | Preview production build |

Requires Node.js 22.23.4+ (see `.nvmrc`).
